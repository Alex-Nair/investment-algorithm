# Investment Automation [W.I.P.]
<b>CURRENT PHASE:</b> Studying and Learning.
<hr>
A simple Python algorithm that will use Artificial Intelligence to manage investments for you, allowing you to make more moeny out of your investments than the standard "Buy and Hold" strategy without any bit of extra effort.

## Implementation
Currently a W.I.P., meaning the final strategy that the AI will use has not been decided yet. However, current ideas include using Artificial Intelligence alongside parallel processing for a constant flow of data to investments through a pipeline, alongside a dual-strategy system to both employ passive and active investing, while mitigating the risks of both.

## Current Status - Studying and Learning
The project currently contains a single Jupyter Notebook which includes all of the code I've written so far to learn the tools I have at my disposal, as well as actively test out strategies.

Once I have found a strategy that seems to perform well, the next stage will be constructing a notebook that actively lets the algorithm interface with the market without any real money (paper trading, but with live updates) in order to test the pipeline.

Once the pipeline has been constructed, and a suitable strategy has been found, the final phase will involve actively applying the strategy to the market using real money, as well as hosting the algorithm so that it can operate 24/7.
