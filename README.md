# Investment Automation [W.I.P.]
<b>CURRENT PHASE:</b> Studying and Learning.
<hr>
A simple Python algorithm that will use Artificial Intelligence to manage investments for you, allowing you to make more moeny out of your investments than the standard "Buy and Hold" strategy without any bit of extra effort.

## Implementation
Currently a W.I.P., meaning the final strategy that the AI will use has not been decided yet. However, current ideas include using Artificial Intelligence alongside parallel processing for a constant flow of data to investments through a pipeline, alongside a dual-strategy system to both employ passive and active investing, while mitigating the risks of both.

## Current Status - Experimentation
Now that the base code has been created and is working, my next step is to start testing various strategies to see if I can come up with something that beast standard "Buy and Hold". This includes both hard-coded strategies, as well as strategies implementing artificial intelligence.

While the simulation isn't 100% accurate (as it currently misses the possibility of day-trading), it works as a starting model, and can be further refined later.
